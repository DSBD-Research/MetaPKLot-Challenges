# MetaPKLot - Challenges

Our implementation of the challenges proposed in the MetaPKLot paper.

Each challenge can be found at:

Challenge 1 - Parking Spot Occupancy Recognition: `classification`

Challenge 2 - Dwell Time: `dwell_time`

Challenge 3 - Parking Spot Extraction: `parking_spot_extraction`

Each folder contains READMEs with instructions the whole pipeline of each challenge.

The non-representative days can be found in the `non_representative_days` folder. Applied only for parking spot extraction.
