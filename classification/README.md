# Parking-Space Classification Challenge

This is the directory of parking-space classification challenge. Here you can find scripts to generate datasets, and code to execute the pipeline for training, testing, and distillation.

The important content of this directory is organized as follows:

<pre>
classification
├── train.py
├── test.py
├── distill.py
├── configs
│   ├── train_validate_cnr_plds_test_pklot.yaml
│   ├── train_validate_pklot_cnr_test_plds.yaml
│   └── train_validate_pklot_plds_test_cnr.yaml
├── scripts
│   ├── generate_dataset.py
│   └── metrics.py
├── src
│   ├── customNNSmall.py
│   ├── Model.py
│   └── PKLotDataset.py
└── README.md
</pre>

train.py is the code for training the ensemble of classifiers. test.py is the code for generating the labels of the ensemble classifiers on the test set. distill.py is the code for training the student models using the labels generated by the ensemble classifiers. We provide three configuration files in the configs folder for training the ensembles. Also, in the scripts folder, we provide a script to generate the datasets used for training, validation, and testing, and metrics.py, which report the results of the experiments in a simplified way, like the results encountered in the results table of the parking-space classification challenge.

Here is how you can execute the whole pipeline of experiments:

## Dataset Generation

After requested the PLds access with the original authors, you will use the following content: 

<pre>
http://www-vpu.eps.uam.es/datasets/PLds/testing/sequences/Images_train.rar
http://www-vpu.eps.uam.es/datasets/PLds/testing/sequences/All_QRIDR.rar
http://www-vpu.eps.uam.es/datasets/PLds/testing/sequences/All_VXUSD.rar
</pre>

Use MetaPKLot-Dataset/tools/PLds/convertPLds2PKLot2.0.py to create PLds annotations on the MetaPKLot format.

After this, you can generate the datasets used in the experiments with MetaPKLot-Challenges/classification/script/generate_dataset.py as follows:

```
python3 generate_dataset.py --pklot /path/to/MetaPKLot-Dataset/ --plds /path/used/in/convertPLds2PKLot2.0.py/ --output /output/
```

Change the paths accordingly, `--pklot` is the path to the MetaPKLot-Dataset folder, `--plds` is the path used in the previous step to convert PLds to MetaPKLot format, and `--output` is the path where you want to save the generated datasets. Note that a folder named `dataset` will be created in the output path, containing the datasets used in the experiments.

## Training the ensembles

For each config in MetaPKLot-Challenges/classification/configs, you will need to adjust the paths.

As an example, here is the config of train_validate_cnr_plds_test_pklot.yaml, wich trains the ensemble on CNRPark-EXT and PLDS in order to test on PKLot:

<pre>
config_path: configs/train_validate_cnr_plds_test_pklot.yaml
transform_resize: [128, 128]
num_epochs: 50
batch_size: 32
normalize: True
datasets_path: ../../dataset # YOU WILL NEED TO CHANGE THIS PATH FOR YOUR GENERATED DATASET PATH
train_val_datasets: [CNRPark-EXT, PLds]
test_datasets: [PKLot]
output_dir: ../../results/train_validate_cnr_plds_test_pklot_large_transfer_learning # YOU CAN CHANGE THIS PATH TO WHERE YOU WANT TO SAVE THE RESULTS
pretrained: True
data_augmentation: True
data_augmentation_prob: 0.1
num_workers: 8 # Adjust according to your machine
val_batch_size: 512 # You can change this value according to your machine
model_type: mobilenet_v3_large
unfrozen_layers: classifier_and_last_conv
mean_std: [[0.485, 0.456, 0.406], [0.229, 0.224, 0.225]]
models_to_train: ensemble
normalize_train_data: True
gray_scale: False
training_mode: partial_ensemble
</pre>

Every path that you may change is highlighted with a comment. After adjusting the paths, you can run the training as follows:

```
python3 train.py --config configs/train_validate_cnr_plds_test_pklot.yaml --gpu 0
```

Here the gpu index 0 is used, you can change it according to your machine. You can also run this command for configs/train_validate_pklot_plds_test_cnr.yaml and configs/train_validate_pklot_cnr_test_plds.yaml to train the ensembles on different datasets.

This will create a folder as follows:

## Generating the labels of the ensembles on the test set

After training the ensembles, you can generate the labels on the test set using test.py as follows:

```
python3 test.py --train_dir /results/folder/ --use_roc_eer_thresholds True --gpu 0
```

Here, `--train_dir` is the path of the ensemble training results, in the example of folder hierarchy shown before it will be the `../../results/train_validate_cnr_plds_test_pklot_large_transfer_learning`. You can change the gpu index according to your machine.

You will need to execute this command only once for every folder of ensembles. In our example, is the `../../results/train_validate_cnr_plds_test_pklot_large_transfer_learning`, `../../results/train_validate_pklot_plds_test_cnr_large_transfer_learning`, and `../../results/train_validate_pklot_cnr_test_plds_large_transfer_learning` folders. If there is more than one execution folder inside the training results folder, the labels will be generated for every execution folder.

At this stage, it is expected to have a folder as follows:

## Training the student models via distillation

Finally, you can train the student models using distill.py as follows:

```
python3 distill.py --train_days 5 --val_days 2 --threshold 0.9 --student_model_type customNNSmall --student_grayscale True --ensemble_models all --use_data_augmentation False  --gpu 0 --train_dir /results/folder/
```

Here, `--train_dir` is also the path of the ensemble training results, in the example of folder hierarchy shown before it will be the `../../results/train_validate_cnr_plds_test_pklot_large_transfer_learning`. You can change the gpu index according to your machine.
